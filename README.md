# Research Showcase

Polished outputs from completed research experiments. Each folder holds the
final paper, results, and supporting artifacts for one experiment — internal
process files (planning, decision logs, prompts) are kept in the private
working repository for each experiment, linked from its folder.

## Experiments

- [`67-when-fair-funding-isnt/`](67-when-fair-funding-isnt/) — Certificate-first exact frontiers and executable audits for public-project mechanisms. [SSRN Abstract 7293498](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7293498)
- [`68-chaotic-equation-identifiability/`](68-chaotic-equation-identifiability/) — "The Chaos Paradox": multi-method empirical test of whether chaotic dynamics aid equation discovery (SINDy, symbolic regression, Koopman/EDMD).
