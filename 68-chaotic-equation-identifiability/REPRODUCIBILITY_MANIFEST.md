# Reproducibility Manifest

## Environment
- Python: 3.14.7 (system `python3`, macOS/Darwin, arm64)
- Virtualenv: `.venv/` (not committed; recreate via `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`)
- Core packages (pinned in `requirements.txt` once frozen): numpy, scipy, sympy, matplotlib, pysindy
- Hardware: local Mac, 16GB RAM, CPU-only, no GPU/cloud used.

## Data
- All data is synthetically generated by `src/simulators.py` from known equations (logistic map, Lorenz system) with fixed seeds. No external datasets. No checksums needed until external sources are added (see `data/README.md`).

## Seeds
- To be fixed per experiment and recorded in each experiment's config file under `experiments/`.

## Commands (to be expanded as implemented)
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pytest tests/
.venv/bin/python scripts/run_simulator_smoke_test.py
```

## Known nondeterminism
- None expected for deterministic ODE/map integration given fixed seeds and fixed integrator tolerances; symbolic regression methods (if using stochastic search) will have their own seed handling documented when implemented.
